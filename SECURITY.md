# Security Policy

## Supported Versions

Only the latest released version receives security fixes.

| Version | Supported |
|---|---|
| latest | ✅ |
| everything else | ❌ |

## Reporting a Vulnerability

Report privately via GitHub:
https://github.com/JoJoJotarou/test-github-project-infra/security/advisories/new

Do not open public issues for security bugs. Expect acknowledgment within
48 hours, and a fix or a public disclosure timeline within 7 days.

Please include the affected version, a description of the impact, and
reproduction steps.
